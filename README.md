# МэтрисЛаб

Сайт метрологической лаборатории «МэтрисЛаб». Компания выполняет поверку, диагностику, калибровку и ремонт портативных и стационарных газоанализаторов.

Рабочий сайт: [metrislab.ru](https://metrislab.ru)

## Что есть на сайте

- описание лаборатории и услуг;
- каталог газоанализаторов с поиском и фильтрами;
- информация о поверке, ремонте и калибровке;
- форма заявки для связи с инженером;
- русская и английская версии.

## Технологии

Проект создан на React, TypeScript, Vite и Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка рабочей версии:

```bash
npm run build
```

## Структура проекта

```text
src/components/   компоненты интерфейса
src/pages/        страницы сайта
src/data/         данные каталога
src/lib/          вспомогательные функции
public/           изображения, переводы и служебные файлы
SITE_STRUCTURE.md план структуры и SEO-развития сайта
```

Данные газоанализаторов хранятся в `src/data/gasAnalyzers.ts`. Чтобы добавить новую модель, достаточно дополнить этот файл и загрузить изображение в `public/images/gas-analyzers/`.
