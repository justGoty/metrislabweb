# SEO и заявки: обновление 9 сентября 2026

Статус: локальная версия. Эта партия изменений еще не опубликована на metrislab.ru.

## Сделано

- Главная, каталог и политика собираются с полноценным HTML: текст, заголовки, ссылки и карточки доступны до загрузки JavaScript.
- Добавлена отдельная страница 404 и конфигурация Apache без подмены всех неизвестных адресов главной.
- Согласованы canonical, внутренние ссылки и sitemap: `/catalog/`, `/privacy/`.
- Название организации в JSON-LD приведено к «МэтрисЛаб». FAQ формируется из тех же текстов, что видит посетитель. Каталог размечен как список существующих моделей, без выдуманных цен, отзывов и наличия.
- В мобильной шапке доступен звонок одним нажатием. Телефон и email также показаны рядом с формой.
- Первый экран стал компактнее, фотография лаборатории на большом экране светлее. Кнопка предлагает узнать стоимость и срок, а не имитирует отсутствующий калькулятор.
- Заголовок и кнопки первого экрана появляются сразу, без задержки на декоративную анимацию.
- Убраны отдельные декоративные англоязычные подписи; исправлено переполнение заголовков на узком экране.
- Форма проверяет количество цифр телефона до отправки. Ошибка не стирает введенные данные; выбранная модель передается из каталога. Ссылка на политику открывается отдельно от заполненной формы.
- Зависимости сборки обновлены совместимыми версиями; `npm audit` после обновления: 0 известных уязвимостей. Это проверка базы зависимостей, не полный аудит безопасности.

## Проверки

- `npm run build`, `npm run lint`, `npm run test:static`.
- 8 статических тестов: HTML, один H1, метаданные, ссылки, изображения, совпадение FAQ и JSON-LD, список моделей, отсутствие зашитого в сборку времени заявки.
- Playwright: главная, каталог, политика и 404 на ширинах 320, 390, 768 и 1440 px; отсутствие горизонтального переполнения и битых изображений.
- Мобильное меню, удержание и восстановление фокуса, поиск, тип, производитель, пустой результат, сброс, передача модели, сохранение языка.
- Форма проверяется исключительно с локально подставленными ответами HTTP 500 и 200. Это не доказательство новой доставки письма. PHP-обработчик не менялся.
- Без JavaScript видны тексты и модели, работают обычные ссылки и FAQ. Отправка формы отключена, контакты доступны.
- Локальный preview: основные страницы HTTP 200; неизвестный адрес, вложенный адрес и отсутствующее изображение HTTP 404. API возвращает HTTP 503 с пояснением о локальном режиме и не раскрывает PHP-исходник.
- Скриншоты: `output/playwright/` (не включаются в Git).

Браузерный сценарий: запустить `npm run preview -- --host 127.0.0.1 --port 4173`, затем `playwright-cli open http://127.0.0.1:4173/` и `playwright-cli run-code --filename scripts/browser-checks.js`. Предварительно создать папку `output/playwright`.

## Перед публикацией

1. Сделать свежую резервную копию сайта на REG.RU, включая правила веб-сервера; сохранить контрольную сумму.
2. Загрузить и сверить сборку `dist`. Не публиковать `dist-ssr`, исходники или локальные файлы проверки.
3. Проверить реальные HTTP 200 для страниц, редиректы на canonical и HTTP 404 для неизвестного URL, вложенного URL и отсутствующего изображения. Локальная проверка Vite не доказывает поведение Apache/Nginx на хостинге.
4. Убедиться, что HTML рабочего сайта содержит H1 и текст без исполнения JavaScript, а старые ресурсы не мешают обновлению.
5. Проверить форму на хостинге; новую контрольную отправку согласовать отдельно. Не менять настройки работающей почты в рамках этой публикации.

## Следующий этап для обращений

- Подключить Яндекс Метрику и цели: клик по телефону, email, начало заполнения, успешная заявка. Нужен доступ к счетчику или его номер; в события не передавать имя, телефон, email и текст заявки. До включения проверить необходимость согласия и актуальность политики.
- Создать содержательные страницы поверки и ремонта: порядок работ, комплектность, фактические ограничения, прием и возврат. Цены, сроки и аккредитацию не выдумывать.
- Проверить Яндекс Вебмастер и карточку компании: реальная индексация, sitemap, регион и контакты. Наличие метатегов само по себе не доказывает индексацию.
- Добавить реальные примеры работ и подтвержденные условия, когда появятся материалы. Telegram остается отложенным.
